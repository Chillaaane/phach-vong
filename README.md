# PHÁCH VỌNG

Website starter cho thương hiệu Phách Vọng.

## Màu thương hiệu
#DB3328 · #1E5736 · #FBEFE3 · #F2A638 · #E95A41 · #2459A9

## Font
Đã tích hợp BTDanta Medium/Bold/ExtraBold do bạn cung cấp.

## GitHub Pages
Upload toàn bộ thư mục lên repository → Settings → Pages → Deploy from a branch → main → /(root).

`images/logo-reference.png` là ảnh logo tham chiếu crop từ brand board bạn gửi. Nếu có file logo SVG/PNG gốc, thay file này bằng logo gốc để dùng cho production.
