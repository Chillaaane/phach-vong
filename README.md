## GitHub Pages

1. Tạo repository `phach-vong`.
2. Upload toàn bộ file trong thư mục này.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: / (root).
7. Save.

Không đổi tên thư mục `fonts` và `images`.

Nội dung lịch sử/di sản cần được kiểm chứng và bổ sung nguồn trước
khi dùng cho website chính thức.
